# v0.1.7-community.4 — Native Windows updater

2026-10-29 · Unofficial prerelease · Existing USA/Europe TU3 installation required.

Download **TTT2-Game-Update-v0.1.7-community.4.exe** and follow
**Next → Browse to the existing game folder → Next → Install → Finish**.
Windows may request administrator permission for Program Files.

## Changes

- Standard Windows update wizard with version and feature notes.
- Native game packaging removes the developer console window and restores
  normal asynchronous file logging. No BAT dependency.
- Existing game shortcut opens the launcher: updated offline play or preserved
  original online play.
- Normal saves/settings retained; recovery files stay outside the game folder.
- Payload checksums, repeat-update preservation and failure rollback.

## Validation and limits

Native packaging/logging, original-launch isolation, clean install/reinstall,
save/settings preservation, forced-failure rollback and native wizard checks pass.
Updater and launcher Windows file versions match this release. The exact updater
and three payload files passed a local Defender gate with protection enabled.

The reported 39–45 FPS slowdown still needs a same-scene retest. FPS recovery,
fresh physical VS/Pair/reconnect, cheat-in-fight, save/restart and live online
acceptance are unverified. Permanent item grants remain preview-only. SMAA is
optional; FXAA matches the original port's AA baseline.

Earlier installers were withdrawn after a Defender alert and are not republished.
The earlier alert has not been declared a false positive; a current local scan
is not independent malware certification. See the archived incident record in
`docs/graphics/ANTIVIRUS_REVIEW_2026-10-29.md`.

No game assets, user saves or proprietary SDK files are included.
